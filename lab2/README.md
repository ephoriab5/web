# Звіт до лабораторної роботи № 2

## Тема
**Назва лабораторної роботи:** Верстка сайту компанії згідно з інструкцією (HTML/CSS)

## Мета роботи
Практично застосувати CSS для оформлення семантичної HTML-структури веб сторінки: підключення зовнішнього CSS, селектори, каскад, specificity, типи блоків і Box Model.



## Виконання роботи
Під час виконання лабораторної роботи було реалізовано:
* **створено** семантичну структуру односторінкового сайту компанії «Акустична варта» (`header`, `main`, `section`, `article`, `aside`, `footer`) у файлі `index.html` та зовнішню таблицю стилів `css/style.css`;
* **використано** різні типи CSS-селекторів для стилізації елементів: селектори елементів (`body`, `h1`, `p`), класів (`.main`, `.hero`), ідентифікаторів (`#main-header`), атрибутів (`input[type="email"]`), а також універсальний селектор (`*`) для скидання відступів та групування селекторів;
* **реалізовано** концепцію блокової моделі (Box Model) із застосуванням властивостей `width`, `height`, `padding`, `border`, `margin` та `box-sizing: border-box`, а також налаштовано відображення елементів за допомогою `display` (block та inline-block);
* **додано** інтерактивні ефекти та плавні переходи (`transition` та ефекти при `hover`) для кнопок і карток, позиціонування (`position: relative` / `absolute`), а також навмисний приклад конфлікту стилів для демонстрації роботи каскаду та специфічності (Specificity).
